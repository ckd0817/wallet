# 云端同步与 Debug 调试

## 使用

Android 设置页提供注册、登录、修改密码和同步操作。用户名为 3～40 个中文、字母、数字、下划线或短横线，密码至少 8 位。首次登录时确认本机账本归属，迁移完成后同一账户的设备共享数据。

未登录时仍可本地记账。登录后的操作先提交 SQLite，再进入上传队列；断网不会丢失已保存的账目。退出后隐藏该账户的数据，重新登录原账户继续同步。

普通记录以服务器最后提交的修改为准；周期账单、定投和交易结算通过固定执行编号去重。后台同步由 Android WorkManager 调度，省电限制或强行停止应用会延后执行，回到前台会重试。

模型地址、模型名、提示词和密钥随账户同步。模型密钥在服务器和手机均加密保存。截图、识别日志、行情缓存、系统权限留在本机。

资产管理支持基金、A 股和美股。美股代码使用大写字母及点号，例如 `AAPL`、`BRK.B`；美股持仓和交易记录以美元保存，人民币与美元资产分别汇总和展示。旧持仓在读取时自动补齐市场和币种，不改变原有记录编号。

## 导入导出与恢复

导出文件格式为 smartwallet-backup v2，包含账单、分类、周期规则、持仓、定投计划、收益历史、交易记录。可读取此前 v1 文件，以及这次迁移使用的原始 JSON。导出可离线完成，也包含尚未同步的修改。

追加导入按记录 ID 去重，已有记录优先。登录后的覆盖导入需要联网，确认前会同步并保存恢复副本；成功后替换该账户所有设备上的账本，常规设置和模型配置保留。

旧设备发现云端已恢复时停止上传，保留原始本机数据与待上传操作。设置页可导出恢复副本，再选择“恢复同步”载入云端账本。需要的旧记录可以随后通过追加导入取回。

恢复请求在手机上持久保存；网络中断后“立即同步”会重试同一个请求。已提交的恢复不会因重试执行第二次。

## Debug 构建与覆盖安装

本项目固定分发 Debug 包，应用 ID 为 com.smartwallet.app。保留开发电脑的 Debug keystore，跨电脑构建时安全复制同一签名文件；不得重新生成已在使用的签名。

在 PowerShell 中：

```powershell
$env:JAVA_HOME='E:\Java\jdk-21'
$env:PATH='E:\Java\jdk-21\bin;'+$env:PATH
npm run android:sync
Push-Location android
.\gradlew.bat :app:assembleDebug
Pop-Location
& 'E:\AndroidStudioSDK\platform-tools\adb.exe' install -r 'android\app\build\outputs\apk\debug\app-debug.apk'
```

签名不一致时先保留原应用和数据，不直接卸载。当前 Debug 证书 SHA-256 为：

```text
792ecb9983686fe090a71f7c4132dece5f9fd9e8838e0c9a7bae8d5bb5dbd2ea
```

查看私有目录与日志：

```powershell
& 'E:\AndroidStudioSDK\platform-tools\adb.exe' shell run-as com.smartwallet.app ls -l databases
& 'E:\AndroidStudioSDK\platform-tools\adb.exe' logcat -s AndroidRuntime SmartWalletCapture
node scripts/export-device-data.mjs 'E:\WalletBackups\debug-inspection'
```

导出脚本会停止应用，使数据库文件和 WAL 保持一致，再导出当前应用的数据归档及 SHA-256。目录应位于仓库外，并限制访问权限。解压后的 wallet-v2.db 可用 SQLite 工具查看：

| 表 | 内容 |
| --- | --- |
| accounts | 每个账户的展示快照、云端基准、数据代次、同步游标和状态 |
| outbox | 待上传操作，按 seq 排序；幂等编号为 id |
| snapshots | 最近 100 个本地版本，用于合并页面操作和后台写入 |
| recovery | 加密的恢复副本，包括尚未同步的操作 |
| requests | 尚未确认结果的覆盖恢复请求 |

accounts.document 中的账本字段可直接查看，apiKey 为加密字符串。登录令牌存储于受 Keystore 保护的配置中。数据库归档用于本机排查；跨设备恢复使用云端账户或 JSON 导入，因为 Keystore 密钥不会随文件归档迁移。

## 测试

```powershell
npm test
npx tsc --noEmit
Push-Location android
.\gradlew.bat :app:testDebugUnitTest
.\gradlew.bat :app:connectedDebugAndroidTest
Pop-Location
```

真机测试辅助 APK 需要手机允许 USB 安装。SQLite 测试使用随机测试账户分区并在结束时清理，不修改已有账户记录。原 JSON 迁移比对测试在首次绑定账户前运行。

服务器测试只允许连接 wallet_test 数据库，详见 server/README.md。
